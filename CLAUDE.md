# CLAUDE.md — MediaButler

How to work in this repo. The *what/why* lives in the Codex docs; this is the *how*.

## Codex (canonical documentation)
This repo follows the MindAttic Codex standard. The source of truth is `docs/`:

- **`docs/BIBLE.md`** (L0) — what MediaButler IS / is NOT, the architecture canon, and the Laws
  (`#MB-LAW-n`). Single home per fact; everything else links to it by `{#MB-...}` anchor.
- **`docs/AMENDMENTS.md`** (L1) — append-only change log (`MB-A1..`). An amendment **wins** over
  the bible. Never rewrite one; supersede it.
- **`docs/USER_STORIES.md`** (L2) — test-cited stories (`MB-US-<Epic><n>`). Every ✅ names the test
  that proves it.
- **`docs/rfc/`** — design notes; graduate into the bible + stories, then mark superseded.
- **`docs/BIBLE.digest.md`** — GENERATED by `tools/codex.ps1`; never hand-edit. Injected at
  session start by `.claude/hooks/inject-digest.ps1`.

Org-wide laws live in `D:/Projects/MindAttic/MindAttic.HouseRules.md` (`#HOUSE-LAW-n`) and are
**inherited by reference** from BIBLE §5 — do not restate or modify them here.

### Working rules
- A fact lives in exactly one layer; cross-reference by stable ID, never by line number.
- Mark a story/law ✅ only when a build or test **proves** it ([HOUSE-LAW-8](../MindAttic.HouseRules.md#HOUSE-LAW-8));
  otherwise 🟡/⬜.
- After editing any `docs/*.md`, run `pwsh tools/codex.ps1 digest` then `pwsh tools/codex.ps1 doctor`.
  `doctor` must pass (it validates front-matter, unique/resolving IDs, ✅-story test tokens, cited
  paths, and digest freshness).
- Whole-number versioning only ([HOUSE-LAW-1](../MindAttic.HouseRules.md#HOUSE-LAW-1)).

## Build / test / run
```powershell
dotnet build MediaButler/MediaButler.csproj
dotnet test  MediaButler.Tests/MediaButler.Tests.csproj   # headless gate (NUnit)
dotnet run   --project MediaButler                         # interactive menu
dotnet run   --project MediaButler -- --dry-run            # force dry-run
```
The `MediaButler.Maui` shell and `MediaButler.Maui.UiTests` are Windows-desktop only and are not
part of the headless test gate.

## Conventions
- This is a .NET 10 Windows console app (assembly `mediabutler`) with an optional MAUI shell.
- Credentials resolve through `MindAttic.Vault`; LLM calls route through `MindAttic.Legion`. Never
  hard-code secrets or a provider SDK (see [MB-LAW-6](docs/BIBLE.md#MB-LAW-6) /
  [MB-LAW-7](docs/BIBLE.md#MB-LAW-7)).
- The landing page deploys via the sibling `MindAttic.Deploy` repo (`.claude/commands/deploy.md`);
  the in-repo `scripts/cli/*` and `index.htm` are dead code.
